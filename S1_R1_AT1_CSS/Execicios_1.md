# Exercício 1
## Atividade de Apropriação
### Analise o código abaixo:

h1{
    color:red;
}
---
Responda:

* Qual é o seletor?
* Qual é a propriedade?
* Qual é o valor?

R: o seletor seria o H1 (alvo da estilização), a propriedade é o color (característica que você deseja alterar) e o valor seria red (estilo aplicado à propriedade).
